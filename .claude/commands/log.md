---
description: Put something that happened on the record against a customer, tank, order or run. A phone call, a site access change, a complaint, a promise.
---

1. Run `npm run fuel -- log "<customer | tank | order | run>" "<what happened, in one or two sentences>"`.
2. Write the note as a fact with a date if one matters ("Jo asked for keep full on the runoff tank from December"), not a summary of the conversation.
3. If the note changes how the tank or account runs (new access instructions, keep full on or off, a new contact), say which record to change and offer the command.
